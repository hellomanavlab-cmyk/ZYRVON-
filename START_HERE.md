## 🎯 How to Get Started

### Step 1: Extract Project (1 minute)
The `zyrvon-website` folder is in `/mnt/user-data/outputs/`

Extract it to your desired location on your computer.

### Step 2: Install Dependencies (2-3 minutes)
```bash
cd zyrvon-website
npm install
```

### Step 3: Start Development (30 seconds)
```bash
npm run dev
```

Browser opens automatically to `http://localhost:5173`

### Step 4: Verify & Customize (30 minutes)
- Check all 7 pages load correctly
- Update brand colors in `src/index.css`
- Update company name in `src/components/Navbar.jsx`
- Replace email address throughout
- Modify page content as needed

### Step 5: Build & Deploy (5 minutes)
```bash
npm run build
npm run preview  # Test production build locally
```

Then deploy `dist/` folder to Vercel, Netlify, or your server.
